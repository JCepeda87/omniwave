Manage Devices

Add device

Channel picks which channel to monitor on a multi-channel receiver (e.g. a dual UR4D or quad ULXD4Q). Each IP is currently tracked as one device, so re-adding the same IP with a different channel replaces this entry rather than adding a second one alongside it.

Auto Discovery

Probes your local network for hosts responding on known Shure (2202) / Sennheiser SSC (45) control ports, then actually speaks each protocol this app knows (ULX-D/QLX-D command strings, UHF-R, PSM1000) to identify what it really is, pulling its real name off the wire when available.
When on, rescans every 20s and automatically adds any newly identified, not-yet-added unit to this session — no manual "Add" click needed.

Import Frequency Plan

Imports the documented interchange formats: a Sennheiser WSM frequency-list or wideband-scan CSV export, or a Shure WWB plain-text frequency list. Native .wwb / .show project files are undocumented proprietary formats and aren't supported — export a CSV/TXT frequency list or scan from WSM/WWB instead.
User Board Layout
Drag a card to reorder it, or pick S / M / L to resize it. This only controls how the User Board is laid out — sizing and order aren't editable from there.
RF Scanner — Frequency Coordination
Modeled on how tools like Shure Wireless Workbench and Sennheiser WSM coordinate frequencies: pick a region's TV/regulatory band plan, mark occupied TV channels, and new frequencies are chosen to avoid those ranges plus 3rd-order intermodulation products against everything already active. This is a planning aid based on publicly documented band plans — verify local regulations before a real deployment.

Spectrum View

Every connected device's real frequency plotted against TV channels and exclusions on one axis, so you can see at a glance what's near what. A device marker turns red when it's flagged in the last "Check for Conflicts" run. Run a scan below to overlay the actual measured RF trace.

TV Channels (click to mark occupied)

Scan-Based Exclusions

Mirrors how WWB itself builds exclusions: sweep the spectrum (muting your own transmitters first so you're reading the ambient environment, not your own gear), then anything crossing the threshold below becomes an excluded range, same as the TV channels above.

Manual Exclusions

Avoid a specific frequency or range regardless of scan/TV data — e.g. one reserved for a news crew, or a venue-specific restriction. Leave "To" blank to exclude a single frequency with a small guard band.

Active Frequencies

Auto-includes each connected device's real, live-reported frequency (falling back to a manually assigned one for devices that don't report it), plus any extra candidates added here. Assigning a new frequency below pushes it live to connected hardware, not just this app's bookkeeping.
Or, like WWB's own Calculate + Assign & Deploy: recompute clean frequencies for every 🔓 unlocked device below at once (🔒 locked devices keep their frequency and anchor the calculation).
